# Evolución de un prompt

Usa el mismo procedimiento/candidato, primero `01_naive`, después contextualiza,
restringe y exige evidencia. Prompts en inglés para facilitar interacción técnica;
el workshop y las discusiones pueden dictarse completamente en español.

No son garantías de corrección. Copia el contrato y código en el contexto disponible
de Genie; no asumas que leyó todo GitHub automáticamente. Los outputs cambian.

| Archivo | Qué añade |
|---|---|
| 01_naive | Petición abierta |
| 02_contextualized | Motor, dominio y entrada/salida |
| 03_constrained | Reglas semánticas |
| 04_verifiable | Diagnóstico, pruebas y evidencia |
| 05_production | Cambio mínimo, revisión y límites de delegación |
